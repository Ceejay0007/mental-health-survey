# Mental Health Survey Analysis

## Overview
This project explores mental health trends among tech professionals using a public survey dataset. It focuses on understanding treatment patterns, employer support, and demographic factors through data cleaning, exploratory analysis, and visualization.

## Objectives
- Clean and standardize survey data for analysis
- Perform exploratory data analysis (EDA) to uncover key insights
- Visualize relationships between gender, age, treatment, and employer benefits
- Prepare the dataset for future modeling and presentation
